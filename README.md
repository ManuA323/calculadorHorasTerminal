# Calculador de horas terminal

Calcula horario de entrada y salida de la oficina, usando eventos del daemon systemd-journald de Linux.

<img width="932" height="387" alt="image" src="https://github.com/user-attachments/assets/00913b17-d690-4b60-8738-5ec81cf150d1" />

Comandos de terminal:

## Instalacion
```console
curl -fsSL https://raw.githubusercontent.com/ManuA323/calculadorHorasTerminal/main/install.sh | bash
```
## Ver tabla principal
```console
horas
```
## Exportar datos a CSV
```console
horas -e
```
## Vista previa de datos CSV
```console
horas -c
```
## Desinstalar
```console
desinstalar-horas
```
